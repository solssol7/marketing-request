# 마케팅 요청 시스템 (Marketing Request System)

마케팅 디자인 자재(X배너, 현수막, 전단지 등)를 효율적으로 신청하고 관리하기 위한 Next.js 기반의 웹 애플리케이션입니다.

## 📌 프로젝트 정보

* **현재 버전**: v0.2.0
* **최근 업데이트**: 2026년 3월 6일
* **주요 목적**: 신청 데이터의 구글 시트 동기화 및 슬랙 실시간 알림 전송

## 🚀 핵심 기능

1. **품목 선택 요약 바 (New)**: 신청 중인 품목을 페이지 상단에서 실시간으로 확인 가능합니다.
2. **스티키 하단 버튼 (New)**: 페이지 길이에 상관없이 '이전/다음' 버튼이 화면 하단에 고정되어 접근성이 향상되었습니다.
3. **복수 품목 분할 저장**: 한 번의 신청에 포함된 서로 다른 품목들을 구글 시트의 개별 행으로 나누어 기록합니다.
4. **강화된 보안 로그**: 단순 성공/실패 외에 요청자의 **IP 주소**와 **기기 정보(User-Agent)**를 함께 기록하여 추적성을 높였습니다.
5. **디자인 관리 최적화**: 디자인 개수를 변수 처리하여 코드 수정 없이 수량 변경에 유연하게 대응합니다.

## 🛠 기술 스택

* **Framework**: Next.js (App Router)
* **Library**: React, Axios
* **API**: Google Sheets API v4
* **Deployment**: Vercel

## ⚙️ 환경 변수 설정

Vercel Settings에서 다음 변수들을 설정해야 합니다:

* `GOOGLE_CLIENT_EMAIL`: 구글 서비스 계정 이메일
* `GOOGLE_PRIVATE_KEY`: 구글 서비스 계정 프라이빗 키 (`\n` 처리 포함)
* `SPREADSHEET_ID`: 대상 구글 스프레드시트 ID
* `SLACK_WEBHOOK_NORMAL`: 일반 알림용 웹훅
* `SLACK_WEBHOOK_DISTRIBUTOR`: 총판 알림용 웹훅
