### 2. 디자인 템플릿 관리 및 업데이트 가이드

새로운 디자인이 추가되었을 때 코드를 수정하는 방법입니다.

* **이미지 서버 업로드**: 새로운 디자인 이미지를 `https://fs.qmk.me/` 경로에 규칙에 맞게 업로드합니다.
* X배너: `template-xbanner-{번호}-202601.webp`
* 현수막: `template-banner-{번호}-202601.webp`


* **코드 반영**:
1. `src/components/DesignModal.js`: `xBannerList` 또는 `bannerList` 배열의 길이를 수정합니다.
2. `src/components/Step2_Items.js`: PC 버전 화면 출력을 위해 동일하게 리스트 길이를 수정합니다.

### 3. 환경 변수 및 설정 매뉴얼 (Setup Guide)

프로젝트 초기화 또는 이전 시 필요한 설정입니다.

* **Google Cloud 권한**: 서비스 계정 이메일을 대상 구글 스프레드시트에 **'편집자'** 권한으로 공유해야 합니다.
* **Slack Webhook**:
* `SLACK_WEBHOOK_NORMAL`: 일반 마트 요청 알림 채널
* `SLACK_WEBHOOK_DISTRIBUTOR`: 이름에 '총판'이 포함된 요청자 전용 알림 채널


* **필수 시트 구성**: '유저 정보', '마트', '내역', '로그' 시트 이름이 정확해야 작동합니다.

---

### 4. 트러블슈팅 및 로그 확인 가이드

문제가 발생했을 때의 대응 절차입니다.

* **로그 시트 확인**: Vercel 로그 대신 구글 시트의 **'로그'** 탭을 먼저 확인합니다.
* `ERROR`: 구글 API 권한 문제, 시트 이름 변경, 또는 필수 환경변수 누락 여부를 체크합니다.


* **슬랙 알림 누락**:
1. 구글 시트 '내역'에 데이터가 들어왔는지 확인합니다.
2. 데이터는 들어왔으나 알림이 없다면 Webhook URL 만료 또는 네트워크 오류(Axios)를 의심해야 합니다.


* **마트 목록 로드 실패**: `api/init` 호출 오류 시 구글 시트의 '마트' 탭 범위가 `A2:E`를 벗어나지 않았는지 확인합니다.
